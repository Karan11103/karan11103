## 🚀 Featured Projects

### [InsightDesk AI](https://github.com/Karan11103/InsightDesk_AI)
An AI operations and quality platform exploring agentic workflows, tool use through MCP, output evaluation, diagnostics, and self-healing QA.

**Focus:** Python · FastAPI · Next.js · TypeScript · LLM evaluation

### [Ghost Payment Detector](https://github.com/Karan11103/Ghost-Payment-Detector)
A payment-reliability project that explores missed webhook events, payment reconciliation, idempotency, audit trails, and safe recovery workflows. AI-generated explanations are separated from the deterministic logic that governs payment-state changes.

**Focus:** Python · FastAPI · React · SQLite · Reliability testing

### [CarWise AI](https://github.com/Karan11103/CarWise-AI)
An AI-powered used-car intelligence project concept focused on vehicle-history checks, visible-condition observations, maintenance-cost estimates, and explainable buyer reports. The repository README describes the intended direction; features should not be assumed implemented until demonstrated.

**Focus:** Machine learning · Data analysis · Computer vision · Python
